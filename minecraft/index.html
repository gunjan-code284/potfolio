GET STARTED

About & How to Join

Follow our simple step-by-step guide to connect to Gunjan's Minecraft Server in seconds.

💻

Java Edition (PC / Mac)

Recommended Experience
  1. Launch Minecraft: Java Edition (Version 1.20.4).
  2. Click Multiplayer on the main menu.
  3. Click the Add Server button.
  4. Set Server Name to Gunjan's Server.
  5. Set Server Address to:
    play.gunjanserver.net
  6. Click Done, select the server, and click Join Server!
📱

Bedrock Edition (Mobile / Win10 / Consoles)

Cross-play Supported
  1. Launch Minecraft Bedrock Edition on your device.
  2. Click Play and navigate to the Servers tab.
  3. Scroll down to the bottom and click Add Server.
  4. Enter Server Name: Gunjan's Server.
  5. Enter Server Address:
    play.gunjanserver.net
  6. Enter Port:
    19132
  7. Click Save and tap Join!
